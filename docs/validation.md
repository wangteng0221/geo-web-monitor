## 真实网页与历史检查

开发期间，两个主流中文AI网页版均有真实单题采集记录。真实回答、账号资料、截图与日志留在私有运行目录，不随公开包分发。早期同机独立目录完成过依赖安装、环境检查、模拟回答及基础操作流程；它不能代替当前所有功能在另一台电脑上的验收。

当前变化动态只将已确认一致的条件用于严格比较。旧记录的联网、思考或模式状态未读取到时，不补猜；条件未知的原文对照单独标注，不算同条件趋势、连续次数或优化效果。失败与缺失也不算品牌消失。

## 正式启用前仍需完成

- 新电脑或其他Windows用户的安装与登录资料行为。
- 当前目标网页版本、地区网络、登录有效性和人工验证；本机需先解除对目标平台的网络访问限制。
- 多真实账号长期运行、长回答停顿及来源采集完整性。
- macOS/Linux、窗口焦点行为及服务器部署。

网络恢复后，使用[团队日常运行手册](operator-runbook.md)完成两个平台、两个问题、连续两次真实运行，并逐条核对原网页、保存正文、账号、引用和截图。该验收通过后才能把工具标为正式上线；在此之前应按试运行使用。采集成功不代表事实正确，也不保证品牌排名提升。

## 可选测试

默认运行 `npm test`。界面测试使用临时数据，可在项目目录的PowerShell中启用：

```powershell
$env:GEO_UI_TEST = "1"
npm test
```

采集器模拟和窗口测试需按对应环境单独运行：

```powershell
$env:GEO_BROWSER_TEST = "1"
node --test --test-timeout=240000 test/browser.test.js test/resume.test.js test/login-pause.test.js
$env:GEO_WINDOW_TEST = "1"
node --test --test-timeout=180000 test/window.test.js
```

这些测试使用本地模拟网页。有窗口用例会打开测试Edge窗口；不要给测试设置真实数据库、账号资料或结果路径。默认跳过的测试不能写成已通过。

公开导出检查核对文件清单、哈希、禁止路径与文档链接，仍需人工审阅内容和图片。详见[隐私说明](privacy.md)、[演示素材](demo.md)、[发布方法](releasing.md)。
